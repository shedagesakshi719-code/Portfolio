## ⚙️ How to Run Locally

Follow these steps to run the portfolio on your computer.

1. Clone this repository:

   ```bash
   https://shedagesakshi719-code.github.io/Portfolio/
   ```

2. Open the project folder:

   ```bash
   cd Sakshi-Portfolio
   ```

3. Open the `index.html` file in your browser, or open the folder in Visual Studio Code and run it using the Live Server extension.

## 🌍 Deployment

This portfolio can be hosted using **GitHub Pages**.

1. Open your portfolio repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Under the build and deployment settings, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Click **Save** and wait for deployment.

Your portfolio will be available at a GitHub Pages URL once deployment is complete.
